# 桌面端与终端安全

对应简历：Electron 客服工作台、Tauri 自动化助手、Windows 终端安全 Agent、浏览器自动化 / CDP。桌面岗和安全岗会问进程模型；后端岗也会用这些项目判断你是否真的做过客户端。

## Q1. Electron 三进程各干什么？preload 为什么必须有？

**怎么答**：

- **Main**：原生能力、窗口、会话、系统权限。
- **Renderer**：UI，默认不该有 Node。
- **Preload**：在隔离环境里向页面暴露白名单 API。
- 客服工作台还内嵌第三方 Web，Renderer 更不可信，所有发消息、读账号都必须走 preload 桥，不能直接 `nodeIntegration: true`。

---

## Q2. partition 如何隔离 WhatsApp / Telegram 多账号？

**怎么答**：

- Chromium `session.fromPartition` 把 cookie、localStorage、缓存隔开，相当于多个浏览器画像。
- 每个客服账号一个 `WebContentsView` + 独立 partition，避免串登录态。
- 代价：内存、代理要按会话配置，启动要复用已有 partition 而不是每次新建。
- 简历「优化复用路径打开性能」指的就是冷启动 vs 复活已有 view。

## Q3. Send Guard / DLP 的状态机怎么设计？

**怎么答**：

发送不是 `input → send`，而是：

1. 拦截即将发出的内容。
2. 翻译预览 / 敏感词 / 黑名单 / 保护词。
3. 人确认或策略放行。
4. 真正调用平台发送。
5. 写审计（只留元数据，不落完整敏感正文，或加密后受控存储）。

失败路径：拦截超时、翻译失败、用户取消，必须停在「未发送」，不能半成功。

敏感字段 AES（简历写 AES-256-GCM）要讲：密钥从哪来、是否按租户、IV 不复用。面试不要求背 API，但要有密钥管理意识。

---

## Q4. RBAC 在桌面客服里和 Web 后台有何不同？

**怎么答**：

- 后台：Admin / Manager / Agent 管人、管词库、管审计。
- 桌面：还要管「能不能看到某个账号的 WebView、能不能跳过 Guard、能不能导出聊天」。
- 权限不能只藏在 UI，Main 进程每次发消息都要鉴权，否则改前端就能绕。

---

## Q5. 为什么自动化助手选 Tauri 2 + Rust，而不是再来一个 Electron？

**怎么答**：

- 工作负载是长循环、代理、CDP、风控，不是复杂 DOM。
- Rust 侧做调度和网络，前端只可视化状态和日志。
- 包体、常驻内存、Windows 安装包都更友好。
- 代价：生态比 Electron 小，WebView 能力和 Chromium 内嵌第三方站点不是同一类需求。

---

## Q6. 用 CDP 采鉴权信息，面试里怎么讲才专业？

**怎么答**：

- 业务目标：站点登录态在浏览器里，自动化要复用 cookie / header 才能调 API，而不是让用户拷 token。
- 做法：本机用户自己的浏览器会话，钩 XHR/Fetch 和请求头，适配不同站点。
- 边界：只用于授权用户自己的双账户对冲助手，凭证存本地加密，不上传。
- 稳定性：站点改版导致选择器 / 请求形态变化，要有适配层和失败熔断，不要写死一份脚本。

不要讲成「破解别人网站」。重点是适配、权限、本地凭证和熔断。

---

## Q7. 双站点对冲主循环里，风控熔断怎么做？

**怎么答**：

简历闭环：登录鉴权 → 策略决策 → 双边执行 → 风控熔断。

- 余额校验失败、一侧下单成功一侧失败、延迟过大、连续错误，都要停。
- 停不是杀进程：要进入可恢复状态，日志可推到前端。
- 代理（SOCKS5 / HTTP）失败要与业务失败区分，否则会误熔断。
- 幂等：同一期号不能对冲两次。

---

## Q8. Windows Agent 做成 Service，和普通托盘程序差在哪？

**怎么答**：

- Service 可在用户未登录时跑、崩溃由 SCM 拉起、更适合「设备心跳 + 管控」。
- 提权：装安装包时进服务账户；运行时不要一直 UAC 弹窗。
- 本地 Axum 健康接口只绑回环，给本机排查，不暴露到局域网。
- 命令轮询：设备出网连管理平台，平台不主动连设备（NAT 友好）。

## Q9. NTFS Deny X 误伤了系统或业务软件怎么办？

**怎么答**：

- 滚动补扫、目录级回退，说明你知道 ACL 会漂、会冲突。
- 白名单要分：系统目录、租户业务软件、临时安装包路径。
- 进程兜底（WMI `Win32_ProcessStartTrace` + ToolHelp）是第二道，不是第一道。
- 远程清除：占用中的文件要先停进程再删，失败要回传原因。
- 兼容性：不同 Windows 版本 ACL 继承不一样，要有安装后自检。

---

## Q10. GitHub Actions 打 Windows 包，如何按租户注入 server_url / tenant_id？

**怎么答**：

- 构建一次核心二进制，安装层或配置文件按租户覆盖，避免每个客户编一份完全不同的制品。
- 密钥不要写进仓库；签名证书走 CI secret。
- 版本、升级、回滚要能讲：Agent 和平台协议版本不匹配时的行为。

这题用来证明你交付的是可运营产品，不是演示 exe。
