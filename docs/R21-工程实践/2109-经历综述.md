## 核心项目

### 1. 数字资产交易平台｜Spring Boot · Dubbo · Apollo · MySQL · Redis · RocketMQ · Netty · Elasticsearch

**项目描述**：数字货币交易所后端微服务体系，覆盖现货 / 合约 / 期权交易、账户资产、链上钱包充提、OTC 法币、开放 API、运营后台与多商户 SaaS。服务间 Dubbo RPC，配置走 Apollo，网关聚合 App / Web / OpenAPI。

**技术亮点**：

- Dubbo + ZooKeeper 服务治理，Apollo 动态配置；按账户、委托、撮合、行情、钱包、用户等领域拆分微服务，RocketMQ 承接下单、成交、充提与强平等异步链路。
- 现货 / 合约采用内存撮合（Redis 热数据 + MySQL 落库）；合约侧含标记价与强平，Netty / WebSocket 推公共行情与用户私有数据。
- 账户账本覆盖余额、划转、充提记账与日终快照；钱包侧支持多链地址、充提与归集；Elasticsearch 支撑检索与经营统计。

**个人贡献**：负责平台环境搭建、服务部署与主链路梳理，跑通下单 → 撮合 → 成交 → 账务 → 充提；围绕委托、撮合、账本、钱包做模块改造、接口联调及资金与稳定性问题排查，保障上线与持续迭代。

服务域与模块对照见 [交易撮合与账务](./2102-交易撮合与账务)。

### 2. 多平台企业客服工作台｜Electron · React · TypeScript · Fastify · Prisma · Vite · Redis

**项目描述**：面向跨境客服场景的一体化工作台，内嵌 WhatsApp / Telegram Web，统一承载多账号会话、实时翻译、DLP 拦截、权限审计与运营管理。

**技术亮点**：

**个人贡献**：打通“多账号会话 → 翻译预览 → 安全发送 → 审计留痕”全链路，完成 WA / TG 双平台接入与企业级权限治理能力建设。

### 3. 终端安全监控 Agent｜Rust · Tokio · Windows Service · WMI · NTFS ACL · GitHub Actions

**项目描述**：面向企业终端的 Windows 安全 Agent，对接管理平台形成“设备上线 → 资产与行为采集 → 应用启动管控 → 远程清除”闭环。

**技术亮点**：

- 使用 Rust + Tokio 实现常驻服务型 Agent，模块化拆分注册心跳、命令轮询、应用 ACL、进程强制、行为采集与软件扫描；本地 Axum 提供健康与状态接口。
- 以 NTFS Deny X 作为白名单外默认不可执行的主防线，支持滚动补扫与目录级回退，兼容不同 Windows 环境。
- 通过 WMI Win32_ProcessStartTrace 事件与 ToolHelp 轮询实现进程管控兜底；结构化命令支持远程清除与占用处理。
- GitHub Actions 产出 Windows 安装包，支持按租户覆盖 server_url / tenant_id 等安装配置。

**个人贡献**：独立完成平台 API 对接、Windows 服务与提权、白名单拦截、进程管控、一键清除、行为与软件采集，以及 CI 打包与安装配置策略。

### 4. ChatCLI 远程 AI CLI 终端控制工具｜Rust · Tokio · Teloxide · tmux · launchd · macOS

**项目描述**：面向移动办公场景的本机终端远程控制工具。用户可通过 Telegram 启动 Codex / Cursor，在指定工作目录中创建真实交互式 tmux 终端，查看终端输出、发送输入并在回到电脑后 attach 至同一会话继续操作。

**技术亮点**：

- 采用 SessionAgent → TerminalManager → tmux → Codex / Cursor 分层架构，隔离会话意图、终端控制与展示逻辑。
- 通过 tmux 保持移动端与本机 Terminal 的真实会话状态；Telegram 侧结合 ANSI 清理、内容截断与消息编辑实现近实时流式展示。
- 使用 Rust 构建终端生命周期与会话管理能力，提供 macOS build / install / start / stop / restart / status / logs / uninstall 运维脚本及 launchd 集成。

**个人贡献**：从 0 到 1 完成 Telegram 与 tmux 的远程交互闭环，负责目录选择、输入转发、Ctrl+C、终端查看、本机接管、会话关闭及本地交付能力建设。
