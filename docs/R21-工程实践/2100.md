# 专题索引

这份题库按当前简历里**会被深挖的承诺**来排，不是通用八股清单。资深岗面试通常分三层：

1. **项目深挖**：你到底做了什么、边界在哪、事故怎么处理。
2. **技术原理**：简历里写过的栈，必须能讲到实现层。
3. **资深判断**：选型、取舍、稳定性、带人与交付。

建议先把 [经历综述](./2109-经历综述) 过一遍，再按下面地图抽题口述。每题尽量用「背景 → 方案 → 你负责的部分 → 结果 / 数字 → 复盘」来答。

## 开场 60 秒

面试官几乎都会说：「先做个自我介绍」。建议压成四句，不要背简历：

1. **定位**：10 年研发，当前在数字资产交易平台做撮合 / 账务 / 钱包，主线是高并发交易 / 资金风控 / 数据平台，近年补齐 AI Agent 与 Rust 桌面端。
2. **代表结果**：最近和同事把公司采购的交易平台源码搭建上线，吃透撮合 / 账务 / 钱包后做改造和排障；打通跨境企业客服工作台；独立交付终端安全监控 Agent。
3. **技术宽度**：Java 微服务是底座，Go / Rust / TS 按场景选型，不是为了多语言而多语言。
4. **求职方向**：资深研发，能从 0 到 1 扛复杂系统，也能把外购交易系统吃透并稳定迭代。

## 数字务必能解释

简历里的量化结果最容易被追问「口径」：

- 日均 5,000+ 资产：是币种维度、账户维度，还是流水条数？
- 24 小时 → 1–2 小时：从发现问题到定位根因，还是到完成调账？
- 对账准确率 99.9%：分母是什么，漏账怎么发现？
- 数仓 6 个月 → 3 个月、效率提升 50%：省的是人数、工期还是重复开发？
- 绩效计算天级 → 小时级、节约 30% 计算成本：对比的是哪一版作业？

答不出口径，数字会被当成包装。准备一句话版本即可。

1. 先过 [项目深挖](./2101-项目深挖)，把 10 个项目的「我负责什么」说死。

3. 最后用 [资深岗场景](./2108-资深岗场景) 练系统设计、事故复盘、跨团队推进。
