# 链上钱包与多链

对应简历：钱包充提与归集、EVM 资产监测与策略、多链节点、智能合约。Web3 岗位会深挖；非 Web3 岗位也会用充提问你资金安全意识。

## Q1. 充值到账为什么不能「看到一笔 transfer 就加余额」？

**怎么答**：

- 要等足够确认数，防重组（reorg）。不同链确认策略不同：ETH 区块确认、BTC 更多块、有的链还看最终性。
- 还要匹配：金额、合约（ERC20 vs 主币）、memo/tag（部分链）、地址是否是平台分配的充值地址。
- 入账要幂等：同一 `txid + logIndex` 只能加一次。
- 失败：扫块落后、节点分叉、合约代币 decimal 搞错。

## Q2. 热钱包、冷钱包、归集是什么关系？

**怎么答**：

- 热钱包：在线密钥，处理提现，余额尽量低。
- 冷钱包：离线，存大部分资产。
- 归集：用户充值地址分散，定期扫进热钱包或冷钱包，降低地址管理成本。
- 风险：归集 gas、权限（多签）、归集过程中的到账窗口要对账系统可见。
- 简历「地址管理与资金归集」要能讲：归集任务失败重试、nonce 管理、避免把用户正在确认的充值扫走造成账务混乱。

## Q3. 提现签名和 nonce 出问题会怎样？

**怎么答**：

- 同一热钱包并发提现必须串行 nonce，否则 pending 卡住后面全部失败。
- 卡 nonce：加速交易（同 nonce 更高 fee）或取消交易，要有明确运维流程。
- 签名机：私钥不出盒，业务系统只出未签名交易。
- 审核：大额提现人工 / 多签，防库被拖后自动提空。

这是资金岗必问，即使你只参与过模块也要讲清边界。

## Q4. 多链 Adapter 抽象哪些能力？SOL / TRX 和 EVM 能同一套吗？

**怎么答**：

简历写了统一封装：RPC / WS 订阅、余额、Gas 估算、构造、签名广播、回执。

- EVM 链之间（ETH / BSC / Base）可以共用大量代码，差在 chainId、gas 模型（legacy vs EIP-1559）、RPC 行为。
- SOL、TRX 账户模型、确认、合约调用都不同，Adapter 只能保证**接口形状**一致，实现必须分开。
- 面试加分：先保证「广播后一定能跟踪到终态」，再谈支持新链的工作量。

## Q5. 监听 pending 交易做策略，最大的工程风险是什么？

**怎么答**：

- pending 不是终态：会丢、会替换、会失败。
- 信号洪泛：必须 Redis 去重，状态机推进，否则重复下单。
- 延迟：你的节点到不了 mempool 优势，策略可能正期望。
- 成本：失败交易同样烧 gas；要有模拟（eth_call）和上限。
- 合规与市场风险：面试里强调风控和失败告警，不强调抢跑细节。

## Q6. 从社交媒体文本里抽 CA 地址，如何减少误触发？

**怎么答**：

- 格式归一：长短、大小写、是否带 `0x`、是否截断。
- 链路识别：地址特征 + RPC `eth_getCode` / 元数据，避免把 ETH 地址当 SOL 用。
- 校验：合约是否存在、是否被标记为垃圾、小数位和买卖税（如果你们做了）。
- 状态机：发现 → 校验 → 执行 → 回执 → 失败重试；任何一步失败都不要静默。

## Q7. 策略任务状态机为什么比「收到信号就发交易」重要？

**怎么答**：

- 资金操作必须可恢复：进程重启后知道哪些单已广播未确认。
- Redis 存状态：信号 ID、tx hash、重试次数、终态。
- 告警：长时间卡在 `submitted` 就是事故。
- 这和交易所账务思维一致：先有不可变事件，再推余额 / 仓位。

---

## Q8. 自建节点 vs 公共 RPC，你怎么选？

**怎么答**：

- 公共 RPC：快，但限流、隐私、memepool 质量差。
- 自建：成本高（简历提过基础设施成本评估），运维重。
- 实践：读和监听可用可靠 SaaS，热路径签名广播用自有或付费专用节点；不要十个链全自建。
- 这能解释为什么项目要做成本复盘。

---

## Q9. 智能合约你写到什么深度？

**怎么答**：诚实分层：

- 若主要是对接：会读 ABI、事件、授权（approve）、常见陷阱（手续费代币、rebase）。
- 若写过 Solidity：准备一个真实合约职责（权限、暂停、提现限制），不要把抄的 ERC20 当代表作。
- 资深后端转 Web3：强调链下系统正确性（回执、对账）往往比再写一个 DEX 合约更匹配你的简历。

---

## Q10. 链上系统和中心化账本如何对账？

**怎么答**：

把本题连回明星项目：

- 钱包模块给对账提供「链上已确认进出」和「平台已入账」。
- 差异类型：确认中、归集在途、手续费、异常地址。
- 没有这条连线，交易所简历是两张皮。
